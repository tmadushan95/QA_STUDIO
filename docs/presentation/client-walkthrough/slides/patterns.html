Do not read the table out. Pick two or three patterns that matter to this audience and tell the story: • Strangler fig with a gateway: we are moving features from the Node worker into .NET in stages. Because the API’s reverse proxy forwards anything it does not handle, each feature moves without the web app noticing. No big-bang rewrite, no risky cut-over. • Registry plus Interpreter: test steps are data, the registry knows each step type, and the interpreter runs them after validating all of them. That is what makes the tool code-free and safe. • Optimistic concurrency: two people editing the same case never silently overwrite each other. Strategy and Adapter appear in AI: Anthropic, Gemini and a fake provider for tests sit behind one interface, so the provider can be swapped.
