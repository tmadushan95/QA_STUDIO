High-priority failures: fix these first

The dashboard is the manager’s page. It answers one question: are we ready to release this version? Six key numbers on top, then panels. Point out “High-priority failures” in particular: it is a ready-made to-do list for the team. Everything respects the header scope, so switching the version from 2.4 to 2.5 instantly shows that release’s picture. Engineering note if asked: the dashboard is a read-only query served by the .NET API with hand-written SQL (Dapper), so it stays fast as the library grows. The numbers are calculated in a pure function that is unit tested.
