Be ready for

Questions clients usually ask

Do testers need to code?

No. Steps come from a catalog and read as sentences. Leads can package flows as custom steps.

Will it work with our app?

It is built for any web app. Each project sets its address, sign-in method and test accounts.

Can AI break things?

AI is optional and only drafts. A person approves; only known steps; no secrets sent.

Where is our data?

In your SQL Server. Secrets are encrypted; evidence files stay on your server.

Does it fit our CI?

Yes. An Azure Pipelines step runs it, fails the build on failures and publishes results.

Could it hit production?

No. Runs only reach allow-listed environments; data-deleting steps need permission.

Prepare a one-line answer for each; they are on the slide so you can leave it up during Q&A. Other questions to be ready for: • “What about apps we cannot reach from the server?” The machine running the worker must be able to open the app in a browser. • “Which browsers?” Runs use Chromium through Playwright today. • “Can we add our own step types?” Yes: custom steps in Project settings without code; new built-in steps are a small change in the worker’s registry. • “How do we install it?” One script builds and starts the API and the worker; SQL Server and Node.js are prerequisites. • “What does it cost to run AI?” Each task has a cap on model calls and answer size, set in settings. If you do not know an answer, say so and follow up; do not guess.
