The idea

Tests are data,
not code.

Describe

Testers build steps from a catalog, in plain words.

Run

A real browser (Playwright) performs them.

See

Everyone sees the same live results and evidence.

This is the one idea to remember. A test step is stored as a small piece of data, for example “click the button named Delete”, not as a line of code. Why it matters to the business: • A tester can create and fix tests without a developer. • The same step works on any web application; nothing is written per application. • Because steps are data, the system can check them before running, and AI output can be checked the same way before anyone trusts it.
