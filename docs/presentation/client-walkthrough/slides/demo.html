Suggested live demo (10 minutes)

1

Pick the scope

Open a project and choose a version in the header. About 1 minute.

2

Generate with AI

Describe a feature, show the coverage bar, save two cases. About 2 minutes.

3

Read the steps

Open a case: steps as sentences, parameter chips. About 2 minutes.

4

Run it

Fresh window mode, one test user, a visible browser. About 2 minutes.

5

Review it

Live run view, evidence, Explain with AI on a failure. About 2 minutes.

6

Close on the dashboard

Pass rate, coverage, high-priority failures. About 1 minute.

The demo follows the five-step loop, so the audience sees the story they just heard. Preparation checklist, the day before: • Start QA Studio (qa-studio.cmd) and open http://127.0.0.1:5080. • A demo project with its application address, sign-in method and at least one sign-in user. • The demo environment is on the allowed list, and the Playwright Chromium browser is installed. • An AI provider key is set, if you will show AI. Have a fallback: a few saved cases ready, in case the network is slow. • One case that fails on purpose, to show the evidence and “Explain with AI”. • Use a visible (not headless) browser so the audience sees the clicks. Timings are suggestions; skip step 2 if AI is not relevant to this client.
