Results arrive live: the page updates itself as each case finishes, with no refresh button. Every status is shown in words and icons as well as colour, which matters for accessibility. The difference between Failed and Blocked is worth explaining: Failed means the app did not behave as expected; Blocked means the case could not start (an invalid step or a missing value), so no time is wasted on a half-run. “Explain with AI” is useful for triage. It separates “the test is out of date, here is a corrected draft” from “this looks like a real defect”. In the second case it changes nothing, so a real bug is never hidden by an automatic test fix.
