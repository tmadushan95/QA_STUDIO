Mainstream, well-supported technologies only; nothing exotic for the client to worry about long term. If asked “why not one language?”: browser automation, Excel parsing and the schema-driven step engine are strongest in Node with Playwright and Zod; storage, security and structured business rules are strongest in .NET with SQL Server. The decision is recorded in our architecture decision records (ADR 0005), together with the plan to move features into .NET step by step where that pays off (ADR 0010). Playwright is Microsoft’s browser automation library; it is the engine that actually clicks in the browser.
