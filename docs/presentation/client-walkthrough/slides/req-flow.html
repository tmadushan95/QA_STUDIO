5

Handler + domain

6

Unit of work

Case and steps saved in one transaction.

7

Notify

The worker is told; the API returns 201.

8

Live update

An event reaches every open page, which refetches.

Follow one real request: a tester creates a test case by hand. The point to land: each layer does exactly one job. The endpoint knows HTTP, the handler knows the use case, the domain knows the rules, the repository knows SQL. That is what makes the system easy to change and to test. Errors are caught at the earliest layer: a bad shape at the validator, a broken rule such as “title is required” in the domain, a duplicate in the database. Every layer returns the same JSON error shape, so the web app can show the message and highlight the exact field. Step 8 is why pages update by themselves: the server only says “test cases changed”, and each open page fetches fresh data.
