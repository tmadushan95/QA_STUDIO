Hands-free and agent-ready

Voice control

Say “Hey QA Studio” or press Ctrl+Space, then open pages, fill forms, run cases or generate cases by voice.

Each command runs the same code as a click, so the same checks apply. Deletes need a spoken “yes”, and voice never types passwords.

MCP server for AI agents

AI assistants such as Claude can search cases, read runs, save step drafts and start runs.

There is deliberately no tool to approve, delete, change settings or read a key.

Same principle as the AI Assistant: new ways in, but no new way around the rules.

These are differentiators; mention them briefly unless the client is interested. Voice: the wake phrase is detected on the device, so audio leaves the browser only after the phrase is heard. Built on LiveKit. It is off by default. MCP (Model Context Protocol) is the standard way AI assistants use tools. QA Studio exposes itself as tools, but every call goes through the normal API, with the same validation and audit trail. An agent can propose a draft and start runs of approved scenarios; it can never approve its own work.
