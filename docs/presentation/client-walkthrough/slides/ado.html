From your CI

A pipeline step starts QA Studio and fails the build if tests fail.

For clients already on Azure Test Plans, this is the biggest integration story: they keep writing manual test cases in Azure DevOps, and QA Studio automates them. “Run full pipeline” performs all six stages with one click, each stage shown live. The Azure Pipelines step means QA Studio becomes a quality gate in their release pipeline: a PowerShell step calls QA Studio with an access token and fails the build if QA Studio’s run fails. Results are published back as an automated test run in the plan, so their existing Azure DevOps reports keep working.
