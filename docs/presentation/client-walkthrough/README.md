# QA Studio Client Walkthrough (presentation)

A 33-slide client deck: the business case, a page-by-page product tour, the architecture, engineering quality, a
live-demo plan and expected questions. Speaker notes are in each slide's `<aside>`.

- **View, present or export (PPTX/PDF):** the live deck on claude.ai, _QA Studio Client Walkthrough_
  (https://claude.ai/artifact/9PmuZnTo8gC3aoy1wouNyr). It is private to its owner unless shared.
- **This folder** keeps the deck's source in git, so changes to it can be reviewed:
  - `deck.json`: title, slide order and sections
  - `deck.css`: the shared look
  - `slides/<id>.html`: one file per slide

These files are rendered by the claude.ai Slides viewer and are not a standalone web page. Before a meeting, fill in the
placeholders on the cover slide (presenter, client, date).
